# 🎓 University Course Management System
### *Organizing Knowledge, Connecting Students, Managing Courses.*

---

## 🌟 Project Overview

Welcome to the **University Course Management System** — a MySQL database project designed to organize and manage essential university information in a structured way.

From student records to course enrollments, this project demonstrates how SQL can transform academic data into meaningful information.

## 🎯 What This Project Does

✨ Maintains student and instructor records  
📚 Organizes courses and academic departments  
🔗 Connects students with their enrolled courses  
📊 Analyzes enrollment data using SQL queries  
🧠 Applies practical database concepts to real-world scenarios  

## 🗃️ Inside the Database

| Table | Purpose |
|---|---|
| 👨‍🎓 Students | Student profiles and enrollment details |
| 📖 Courses | Course names, departments, and credits |
| 👩‍🏫 Instructors | Instructor information |
| 🏢 Departments | University department records |
| 📝 Enrollments | Student-course relationships |

## 💻 SQL Skills in Action

This project includes **16 practical SQL tasks**, covering:

- 🔹 CRUD Operations
- 🔹 Filtering, Sorting, and Limiting Results
- 🔹 Aggregate Functions
- 🔹 GROUP BY and HAVING
- 🔹 INNER JOIN and LEFT JOIN
- 🔹 Subqueries
- 🔹 Date and String Functions
- 🔹 Window Functions and Running Totals
- 🔹 CASE Statements
- 🔹 Department-wise Enrollment Analysis

## 🛠️ Technology Stack

**Database:** MySQL 8.0  
**Development Tool:** MySQL Workbench  
**Query Language:** SQL  

## 🚀 Getting Started

1. Open MySQL Workbench.
2. Open the project SQL file.
3. Execute the SQL statements in the correct order.
4. Explore the results and practice the included SQL concepts.
